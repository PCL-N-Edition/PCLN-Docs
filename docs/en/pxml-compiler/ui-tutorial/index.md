# PXML UI tutorials

These tutorials are for developers building their first PCL.UI.Next interface with PXML. Each example keeps the complete build path visible and verifiable:

```text
PXML source → validation → expansion and optimization → PXB → PCL.UI.Next Runtime
```

## Learning path

1. [Create your first UI](./First-Page): write a `Page` with a `Column`, `Text`, and `Button`, then build and inspect its PXB.
2. Layout and sizing: combine Stack, Grid, Overlay, Absolute, and length constraints.
3. Data and interaction: use pure bindings, commands, and structural directives.
4. Components and templates: extract reusable components, properties, and slots.
5. Styles and resources: organize PXSS, theme tokens, localization, and resources.

The first chapter is available now; later chapters will be added to this category. The compiler performs build-time transformation only. PCL.UI.Next Runtime owns windows, input, layout, animation, and rendering.
